# AI for Business Analysts companion files

These optional worksheets and case files accompany *AI for Business Analysts* by Satish Mittal. The Northstar examples use fictional people, records, and data. The worksheets work with a spreadsheet, text editor, or notebook.

| File | Where to use it |
| --- | --- |
| [Workflow inventory](01-workflow-inventory.csv) | Chapter 1. Compare three recurring tasks and select a first trial. |
| [Task brief](02-task-brief.md) | Chapter 2. Set the purpose, source, labels, boundaries, output, and checks for a task. |
| [Verification sheet](02-verification-sheet.csv) | Chapter 2. Record the evidence and corrections for a working output. |
| [Northstar source packet](northstar/01-source-packet.md) | Chapters 3, 4, and 10. Work from the sales note, workshop extracts, and customer complaint. |
| [Northstar completed examples](northstar/02-completed-examples.md) | Chapters 4 through 10. Compare your analysis frame, traceability links, and pilot decision with the examples. |
| [Northstar weekly report](northstar/03-weekly-report.csv) | Chapter 7. Calculate regional variance using the four regional rows and reconcile the results to the Total row. |
| [Northstar source register](northstar/04-source-register.md) | Appendix C. Check the IDs and decision status as you work through the case. |
